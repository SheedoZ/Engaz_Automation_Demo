# ENGAZ Automation V2 Demo

This public GitHub Pages repository contains a synthetic, browser-local demonstration of ENGAZ Automation V2.

- All names, phone numbers, messages, scores, and totals are synthetic examples.
- The demo runs in the browser only. It has no API, network integration, message delivery, form submission, or persistence.
- Do not enter customer data or other personal information; use the supplied demo values only.
- The page intentionally keeps `noindex, nofollow` enabled for this demonstration.

The custom domain is `automation.engaz.premiumpower-eg.com`.
